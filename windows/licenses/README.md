# Runtime license notices

`NODE-22.13.0-LICENSE.txt` is the unmodified Node.js v22.13.0 LICENSE downloaded from https://raw.githubusercontent.com/nodejs/node/v22.13.0/LICENSE. It includes the Node runtime's third-party notices and permits offline packaging with the corresponding installed runtime.

`prepare.js` selects notices matching the exact build-time Node version; other versions are downloaded from their official version tag with bounded retries.
